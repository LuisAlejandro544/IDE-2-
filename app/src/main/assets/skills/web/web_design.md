# 🎨 Skill: Diseño UI/UX HTML5/CSS & Estética M3
- Aplica principios de Material Design 3, jerarquía visual clara y generoso espacio negativo.
- Usa paletas de colores coherentes (fondos oscuros elegantes #121318 / #1A1C23 o temas claros limpios, acentos vibrantes).
- Tipografía profesional, tamaños proporcionales (rem) y alto contraste para legibilidad.
- Bordes redondeados (12px-16px), sombras suaves (box-shadow) y micro-interacciones (hover, active, transitions 0.2s ease).
- Componentes e interfaces pulidas que evitan la apariencia genérica.
