# ⚛️📱 Skill: Adaptabilidad & Responsive Design en React
- Maquetación adaptativa condicional basada en estado de pantalla o clases responsivas (Tailwind / CSS Grid / Flexbox).
- Componentes móviles dedicados (paneles desplegables, barras inferiores) y adaptables a escritorio (sidebars, grids multicolumna).
- Touch targets accesibles en botones e inputs en React con un área de interacción mínima de 48px.
- Desplazamiento suave y contenedor sin desbordamientos horizontales (`max-width: 100%`, `overflow-x: hidden`).
