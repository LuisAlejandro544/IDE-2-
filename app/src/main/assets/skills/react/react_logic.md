# ⚛️⚡ Skill: Lógica React 18, Hooks, Import Maps & Módulos ES
- Programación reactiva y funcional usando Hooks estándares (`useState`, `useEffect`, `useCallback`, `useMemo`, `useRef`, `useContext`).
- Soporte nativo para JSX transpilado en tiempo real con Babel standalone (`<script type="text/babel" data-type="module" src="app.jsx">`).
- Import Maps para React 18:
  • `<script type="importmap">` vinculando `react`, `react-dom/client`, e íconos/librerías (ej: `lucide-react`, `canvas-confetti`, `framer-motion`) desde CDNs ES (`https://esm.sh/`).
  • Importaciones limpias: `import React, { useState, useEffect } from 'react';` e `import ReactDOM from 'react-dom/client';`.
- Inmutabilidad estricta del estado y manejo de datos asíncronos (`async/await`, `fetch`).
- Control explícito de ciclos de vida de efectos para evitar renders infinitos o fugas de memoria.
